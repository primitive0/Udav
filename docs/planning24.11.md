1) язык должен запускаться и выполнять код

Конструкции языка
1) объявление символов
- динамическая типизация
2) переиспользование символов
```
let x = 3
x = 2
```
3) операции с числами:
- (`+` | `-` | `*` | `/`)
- степень `**`
- побитовые операции (`&` | `|` | `^` | `~`) число и bool не поддерживаются
4) операции со строками
- сложение

5) булевые операции
- (`&&` | `||` | `!`) (1)
- Short-circuit evaluation (2)

6) Поддержка скобочек для приоритета
7) ввод/вывод 
- print(...interface)
- println(...interface)
- readln()

8) перевод типов
- int()
- string()
- bool()

9) if
10) while (3)
- break, continue (4)
11) функции
- в случае, если функция ничего не возвращает и мы пытаемся присвоить переменной значение функции, то это ошибка
- параметры всегда передаются по значению
- инструкция return

Список типов:
- void
- Целый (bigint)
- Строковый ""
- bool
