# Типы данных

## Динамическое преобразование типа переменной

Тип переменной автоматически меняется при изменении значения. \

**Пример:** если переменная `a` была типа `int`, но в последующей логике ей присвоили значение типа `string`, то значение и тип переменной поменяются без ошибок
