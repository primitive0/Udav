# Типы данных

Языком будет поддерживаться только 3 типа данных

- **int** - целый
- **string** - строковый
- **bool** - булевый

## Динамическое преобразование типа переменной

Тип переменной автоматически меняется при изменении значения. \

**Пример:** если переменная `a` была типа `int`, но в последующей логике ей присвоили значение типа `string`, то значение и тип переменной поменяются без ошибок

## Целый тип данных

Поддерживает все возможные операторы:

### Арифметические операторы

| Оператор | Описание           |
|:---------|:-------------------|
| `+`      | Сложение           |
| `-`      | Вычитание          |
| `*`      | Умножение          |
| `/`      | Деление            |
| `%`      | Остаток от деления |
| `**`     | Степень            |

### Побитовые операторы

| Оператор | Описание           |
|:---------|:-------------------|
| `&`      | Побитовое И (AND)  |
| `\|`     | Побитовое ИЛИ (OR) |
| `^`      | Побитовый XOR      |
| `<<`     | Сдвиг влево        |
| `>>`     | Сдвиг вправо       |

Правило:

```myebnf
expression<int> = 
    expression<int> operator expression<int>
```

Для корректного выполнения необходимо, чтобы и правый и левый элемент оператора были типа `int` \

Если правило нарушено, то произойдёт ошибка выполнения

## Булевый тип данных

Поддерживает операторы

| Оператор | Описание            |
|:---------|:--------------------|
| `&&`     | Логическое И (AND)  |
| `\|\|`   | Логическое ИЛИ (OR) |
| `!`      | Логическое НЕ (NOT) |

```myebnf
expression<bool> = 
    expression<bool> operator expression<bool>

expression<bool> = 
    ! expression<bool>
```

## Преобразования между типами

Udav - язык с динамической строгой типизацией. Это значит, что неявных преобразований между типами не будет. Если конструкция или оператор подразумевает использование конкретного типа, но на вход в него подали неожиданный тип, то выполнение завершится ошибкой. \

Для преобразования между типами стоит использовать встроенные функции:

```Udav
int()
string()
bool()
```

## Семантика преобразований

### int()

Пытается преобразовать входное значение к типу int

```myebnf
int(expression) =
    expression<int>

int(true) = 1

int(false) = 0
```

### int() runtime error

1) если строковое значение, поданное на вход содержит нецифровые символы. Пример:

    ```Udav
    int("1a435")
    ```

### string()

Преобразовывает входное значение к типу string

```myebnf
string(expression) =
    expression<string>

string(true) = "true"

string(false) = "false"
```

### bool()

Преобразовывает значение к типу bool

```myebnf
bool(expression) = 
    true | false

bool("") = false
bool(0) = false
```

## Встроенные функции для работы с типами

### string

#### reverse()

```myebnf
reverse(expression<string>) = string
```

принимает строку и возвращает её символы в обратном порядке

#### index_of()

```myebnf
index_of(str: expression<string>, substr: expression<string>) = int
```

возвращает число - первое вхождение подстроки substr в строку str

если подстрока не была найдена, возвращает `-1`

#### slice()

```myebnf
slice(str: expression<string>, start: int, end: int) = string
```

возвращает подстроку от исходной строки

если числа start или end выходят за пределы строки -> `runtime_error`
если start > end -> `runtime_error`

#### len()

```myebnf
len(str: expression<string>) = int
```

возвращает число - количество символов в строке

если в строке присутствуют символы по типу `\n`, `\t`, они тоже учитываются
