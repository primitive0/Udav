## Операторы

### Арифметические операторы

| Оператор | Описание           |
|:---------|:-------------------|
| `+`      | Сложение           |
| `-`      | Вычитание          |
| `*`      | Умножение          |
| `/`      | Деление            |
| `%`      | Остаток от деления |
| `**`     | Степень            |

### Логические операторы

| Оператор | Описание            |
|:---------|:--------------------|
| `&&`     | Логическое И (AND)  |
| `\|\|`   | Логическое ИЛИ (OR) |
| `!`      | Логическое НЕ (NOT) |

### Побитовые операторы

| Оператор | Описание           |
|:---------|:-------------------|
| `&`      | Побитовое И (AND)  |
| `\|`     | Побитовое ИЛИ (OR) |
| `^`      | Побитовый XOR      |
| `<<`     | Сдвиг влево        |
| `>>`     | Сдвиг вправо       |

Побитовые операторы с отрицательными операндами запрещены. Результат использования - ошибка выполнения

Пример:
```udav
3 << -2 # ошибка выполнения
```


### Оператор вызова функции

**Оператор вызова функции** - это постфиксный оператор выражений, предназначенный
для вычисления значения путём применения к упорядоченному набору аргументов

Результатом применения оператора может являться:
- вычисленное значение
- аварийное завершение (ошибка выполнения).

#### Аргументы

**Аргументы оператора функции** - это конечная, упорядоченная последовательность выражений 
(выражение - expr в [grammar.ebnf](grammar.ebnf)), заключённая в скобки оператора вызова и предназначенная 
для передачи значений вызываемой функции

Порядок вычисления аргументов - слева направо

Количество передаваемых аргументов должно соответствовать количеству параметров функции

#### Разрешение имени функции

Все функции, объявленные в программе, доступны к вызову

```udav
fun foo():
    println("hello world")
    
fun bar():
    foo() 
    
fun main():
    foo()
```

```udav
fun a():
    b()
    
fun b():
    a()
    
fun main():
    a()
```

### Арифметические выражения

Арифметические выражения включают базовые математические операции: сложение, вычитание, умножение, деление, степень.

```Udav
d = a + b - c * 4 - (2 + 5) / 3
let a = b ** 2
```

### Выражения со строками

Строки в Udav могут быть использованы в выражениях, включая конкатенацию с помощью оператора `+`.

```Udav
let greeting = "Hello" + " " + "World"
```

### Булевые выражения

Булевые выражения поддерживают операторы сравнения и логические операторы (AND, OR, NOT).

```Udav
let flag = true
flag = true || false && true || !false
```
