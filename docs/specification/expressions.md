## Операторы

### Арифметические операторы

| Оператор | Описание           |
|:---------|:-------------------|
| `+`      | Сложение           |
| `-`      | Вычитание          |
| `*`      | Умножение          |
| `/`      | Деление            |
| `%`      | Остаток от деления |
| `**`     | Степень            |

### Логические операторы

| Оператор | Описание            |
|:---------|:--------------------|
| `&&`     | Логическое И (AND)  |
| `\|\|`   | Логическое ИЛИ (OR) |
| `!`      | Логическое НЕ (NOT) |

### Побитовые операторы

| Оператор | Описание           |
|:---------|:-------------------|
| `&`      | Побитовое И (AND)  |
| `\|`     | Побитовое ИЛИ (OR) |
| `^`      | Побитовый XOR      |
| `<<`     | Сдвиг влево        |
| `>>`     | Сдвиг вправо       |

### Оператор вызова функции

**Оператор вызова функции** - это постфиксный оператор выражений, предназначенный
для вычисления значения путём применения к упорядоченному набору аргументов

Результатом применения оператора может являться:

- вычисленное [значение](top-level-grammar.md#возвращаемое-значение-функции)
- аварийное завершение (ошибка выполнения).

#### Аргументы

**Аргументы оператора функции** - это конечная, упорядоченная последовательность выражений
(выражение - expr в [grammar.ebnf](grammar.ebnf)), заключённая в скобки оператора вызова и предназначенная
для передачи значений вызываемой функции

Порядок вычисления аргументов - слева направо

Количество передаваемых аргументов должно соответствовать количеству параметров функции, иначе - ошибка выполнения

[Что такое параметры функции](top-level-grammar.md#параметры-функции)

#### Разрешение имени функции

Все функции, объявленные в программе, доступны к вызову

[Имена функции](top-level-grammar.md#имена-функций)

```udav
fun foo():
    println("hello world")
    
fun bar():
    foo() 
    
fun main():
    foo()
```

```udav
fun a():
    b()
    
fun b():
    a()
    
fun main():
    a()
```

## Типы выражений

Язык `Udav` поддерживает 4 типа данных

- **int** - целый
- **string** - строковый
- **bool** - булевый
- **null**

### Целый тип данных

Представляет собой целочисленный тип данных, не имеющий ограничений (переполнение невозможно)

Литерал целого типа данных - набор цифр от 0 до 9

Лидирующие нули на процесс выполнения не влияют

```udav
000009 # тоже самое, что 9
```

#### Операции

Операции над целыми числами поддерживают следующие операторы

| Оператор | Описание           |
|:---------|:-------------------|
| `+`      | Сложение           |
| `-`      | Вычитание          |
| `*`      | Умножение          |
| `/`      | Деление            |
| `%`      | Остаток от деления |
| `**`     | Степень            |
| `&`      | Побитовое И (AND)  |
| `\|`     | Побитовое ИЛИ (OR) |
| `^`      | Побитовый XOR      |
| `<<`     | Сдвиг влево        |
| `>>`     | Сдвиг вправо       |

Выполнение операций "деление" и "остаток от деления" с делителем, равным 0 - ошибка выполнения

Выполнение любых операций требует, оба элемента оператора были целого типа. Иначе - ошибка выполнения

```udav
1 + "a" # Ошибка выполнения
```

#### Особенности операций над отрицательными числами

1) Деление `/`
   Целочисленное деление в языке Udav определяется
   как алгебраическое частное, усечённое в сторону нуля.
    ```udav
    -5 / 2 # результат: -2
    ```
2) Остаток от деления `%`
   Использование отрицательного числа в
   качестве **делителя** при выполнении операции остатка от
   деления - запрещено. Результат - ошибка выполнения

   Использование отрицательного числа в качестве делимого допустимо.
   Результат - значение, которое будет удовлетворять выражению
   `(a / b) * b + a % b = a`, где `a` - делимое, `b` - делитель
3) Побитовые операторы с отрицательными операндами запрещены.
   Результат использования - ошибка выполнения

    ```udav
    3 << -2 # ошибка выполнения
    ```

#### Функции для работы с числами

##### `int()`

Пытается преобразовать входной аргумент к целочисленному типу

```udav
int("123") # = 123
int(true) # = 1
int(false) # = 0
int(null) # = 0
```

Если строковое выражение, поданное в качестве аргумента
содержит не цифровые символы, результат - ошибка выполнения
Пример:

```udav
int("1a435")
```

### Строковой тип данных

Литерал для строкового типа данных - набор символов, заключённый в двойные кавычки
В том числе поддерживает escape-последовательности (`\n`, `\t`, и пр.)

```udav
""
"1233"
"hello\n" # также поддерживаются escape-последовательности
```

#### Операции

Язык поддерживает следующие операторы

| Оператор | Описание     |
|:---------|:-------------|
| `+`      | конкатенация |

Для оператора `+` правый и левый операнды должны быть строкового типа.
В случае нарушения правила - ошибка выполнения \
Результатом конкатенации строк является строка

#### Функции для работы со строками

##### str()

Преобразовывает входной аргумент к строковому типу

```udav
str(true) # = "true"
str(false) # = "false"
str(2134) # = "2134"
str() # = ""
str(null) # = ""
```

##### reverse()

```udav
# str: string
# return: string
fun reverce(str):
    ...
```

Принимает строку и возвращает её символы в обратном порядке \

##### find_substr()

```udav
# str: string
# substr: string
# return: int
fun find_substr(str, substr):
    ...
```

Принимает 2 аргумента строкового типа

Возвращает число - первое вхождение подстроки substr в строку str \

Если подстрока не была найдена, возвращает `-1`  \

##### substr()

```udav
# str: string
# start: int
# end: int
# return: string
fun substr(str, start, end):
    ...
```

Принимает исходную строку, позицию (начиная с 0) начального и конечного символов

Возвращает подстроку от исходной строки \

Если числа `start` или `end` выходят за пределы длины строки - ошибка выполнения\
Если `start` > `end` - ошибка выполнения \

##### len()

```myebnf
len(str: expression<string>) = int
```

```udav
# str: string
# return: int
fun len(str):
    ...
```

Возвращает число - количество символов в строке \

Если в строке присутствуют символы по типу `\n`, `\t`, они тоже учитываются

### Булевый тип данных

Литералы булевого типа данных: `true` и `false`

#### Операции

Булевый тип данных поддерживает следующие операторы

| Оператор | Описание            |
|:---------|:--------------------|
| `&&`     | Логическое И (AND)  |
| `\|\|`   | Логическое ИЛИ (OR) |
| `!`      | Логическое НЕ (NOT) |

Попытка применить эти операторы к другим типам данных - ошибка выполнения

```udav
"234" || true # ошибка!
```

Операции над булевым типом данных поддерживают short circuit:

```udav
fun foo():
    1 / 0 # ошибка 
    
fun main():
    if true && foo(): # ошибки здесь не будет
        println("hello!")

```

#### Функции для работы со строками

##### bool()

Преобразовывает входной аргумент к типу bool

```udav
bool(123) # = true
bool("hi") # = true
bool("") # = false
bool(0) # = false
bool(null) # = false
```

Случаи с `""`, `0` и `null` - единственные, когда функция вернёт false

### null

`null` - это специальное значение, представляющее отсутствие значения

Над этим типом нет никаких операций
