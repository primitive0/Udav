# Семантика языка Udav

## Типы данных

Языком будет поддерживаться только 3 типа данных

- **int** - целый
- **string** - строковый
- **bool** - булевый

поддержки вещественного типа данных на данном этапе не будет (возможно, он будет реализован как bigdecimal в java)

### Преобразования между типами

Udav - язык с динамической строгой типизацией. Это значит, что неявных преобразований между типами не будет. Если конструкция или оператор подразумевает использование конкретного типа, но на вход в него подали неожиданный тип, то выполнение завершится ошибкой. \

Для преобразования между типами стоит использовать встроенные функции:

```Udav
int()
string()
bool()
```

### Динамическое преобразование типа переменной

Тип переменной автоматически меняется при изменении значения. \

**Пример:** если переменная `a` была типа `int`, но в последующей логике ей присвоили значение типа `string`, то значение и тип переменной поменяются без ошибок

### Целый тип данных

Поддерживает все возможные операторы:

#### Арифметические операторы

| Оператор | Описание           |
|:---------|:-------------------|
| `+`      | Сложение           |
| `-`      | Вычитание          |
| `*`      | Умножение          |
| `/`      | Деление            |
| `%`      | Остаток от деления |
| `**`     | Степень            |

#### Побитовые операторы

| Оператор | Описание           |
|:---------|:-------------------|
| `&`      | Побитовое И (AND)  |
| `\|`     | Побитовое ИЛИ (OR) |
| `^`      | Побитовый XOR      |
| `<<`     | Сдвиг влево        |
| `>>`     | Сдвиг вправо       |

Правило:

```myebnf
expression<int> = 
    expression<int> operator expression<int>
```

Для корректного выполнения необходимо, чтобы и правый и левый элемент оператора были типа `int` \

Если правило нарушено, то произойдёт ошибка выполнения


### Булевый тип данных

Поддерживает операторы

| Оператор | Описание            |
|:---------|:--------------------|
| `&&`     | Логическое И (AND)  |
| `\|\|`   | Логическое ИЛИ (OR) |
| `!`      | Логическое НЕ (NOT) |

```myebnf
expression<bool> = 
    expression<bool> operator expression<bool>

expression<bool> = 
    ! expression<bool>
```
