## Область видимости переменных

### Правила

- Переменные, объявленные на уровне функции, доступны во всей функции и только внутри этой функции.
- Переменные, объявленные внутри вложенного блока, доступны только внутри этого блока.
- Попытка обратиться к недоступной переменной заканчивается ошибкой.

```Udav
fun main():

        let b = "2"
    print(b)  # Ошибка: Область видимости `b` не распространяется на эту строку
    foo()
```

## Имена переменных

При объявлении имена не должны дублировать названия функций (`int`, `string`) и служебных конструкций языка (`if`, `fun`). Если в коде объявлена переменная, дублирующая название функций языка, это вызовет `runtime_error`

Также нельзя переопределять имена, зарезервированные языком программирования. Если это произойдёт -> `runtime_error`

Имена переменных можно свободно переиспользовать согласно пункту `Динамическое преобразование типа переменной` в файле `types.md`

## Рекурсия

### Обычная рекурсия

Функция вызывает саму себя для решения подзадачи того же типа.

```udav
fun factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)
```

### Взаимная рекурсия

```udav
def is_even(n):
    if n == 0:
        return True
    return is_odd(n - 1)

def is_odd(n):
    if n == 0:
        return False
    return is_even(n - 1)
```

### Семантика

1) Рекурсивный вызов создает новый фрейм в стеке вызовов
2) Каждый вызов имеет свою локальную область видимости
3) Базовый случай (терминальное условие) обязателен для завершения рекурсии
4) Взаимная рекурсия требует корректного определения функций до их использования

## Ветвления

### Условный оператор if

```udav
if x > 0:
    result = "positive"
```

### Конструкция if-else

```udav
if x > 0:
    result = "positive"
else:
    result = "non-positive"
```

### Конструкция if-elif-else

```udav
if x > 0:
    result = "positive"
elif x < 0:
    result = "negative"
else:
    result = "zero"
```

### Семантика if-else

1) Условия вычисляются последовательно сверху вниз
2) Выполняется блок первого условия с истинным значением
3) elif проверяется только если все предыдущие условия ложны
4) else выполняется если ни одно условие не истинно
5) Ложными значениями считаются: false, 0, ""
6) Все остальные значения считаются истинными

## Циклы

### Базовый цикл while

```udav
i = 0
while i < 5:
    print(i)
    i += 1
```

### Цикл while с else

```udav
i = 0
while i < 5:
    print(i)
    i += 1
else:
    print("Цикл завершен")
```

### Цикл с break

```udav
i = 0
while True:
    if i >= 5:
        break
    print(i)
    i += 1
```

### Цикл с continue

```udav
i = 0
while i < 5:
    i += 1
    if i % 2 == 0:
        continue
    print(i)
```

### Семантика while

1) Условие цикла проверяется перед каждой итерацией
2) Если условие истинно, выполняется тело цикла
3) Если условие ложно, цикл завершается
4) break немедленно завершает весь цикл
5) continue пропускает оставшуюся часть итерации и переходит к проверке условия
6) Блок else выполняется только если цикл завершился естественным путем (без break)
7) Цикл может стать бесконечным если условие всегда истинно и нет break

## Прочие правила

### Функции

функции в которых нет оператора `return`, не должны использоватся как `rvalue`

```udav
let x = returns_nothing() # runtime error
```

### Операторы == и !=

операторы `==` и `!=` сравнивают любые типы данных

Если типы разные, результат - `false`

```udav
let x = 1 && "1" # false
```
