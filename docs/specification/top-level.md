## Функция

Функция - это именованная, лексически замкнутая вычислительная абстракция,
определяющая отображение из упорядоченной последовательности входных значений (параметров)
в результат вычисления и/или побочные эффекты \

### Имена функций

Каждая функция должна обладать именем

Каждое имя функции - уникально и не может быть переиспользовано
для объявления другой функции повторно. Результат - ошибка выполнения

Имя функции используется для того, чтобы потом обратиться к ней для вызова

```udav
fun foo():
    ...
    
fun foo(a): # ошибка выполнения
    ...

```

#### Зарезервированные имена функций

В языке существуют зарезервированные имена функций, которые нельзя использовать
при написании кода. Попытка - ошибка выполнения

К ним относятся:

1) Встроенные функции работы с типами (`int`, `bool`, `substr` и пр.)
2) Имена инструкций по типу (`let`, `continue` и пр.)
3) Имя `main`

### Объявление функции

Функция объявляется ключевым словом fun, далее идёт имя и набор параметров в скобках

Пример объявления функции

```udav
# Здесь foo - имя фукнции
# a, b, c - список параметров
fun foo(a, b, c):
    ...
```

### Параметры функции

Параметры функции - это упорядоченная последовательность именованных переменных,
объявляемых в определении функции и предназначенных для получения значений аргументов при её вызове

Их количество может быть произвольным

### Возвращаемое значение функции

Функция всегда возвращает значение

Если функция была вызвана в виде [expr](grammar.ebnf), то результатом `expr` будет значение,
которое вернула функция

По умолчанию любая функция возвращает значение `null`

Значение можно изменить, используя инструкцию [return](#return)

## Основная программа

Основная программа в языке начинается с функции с именем `main`

В программе не должно быть более или менее 1 функции `main`. Иначе - ошибка выполнения

```udav
func main():
    ...
```

```udav
func not_main(): # ошибка выполнения - нет функции main
    ...
```

```udav
func main():
    ...
    
func main(): # ошибка выполения - повторно объявленная функция main
    ...
```

## Инструкции

### Инструкции на уровне [program](grammar.ebnf)

Допустимые инструкции на уровне `program`

- Объявление функции

Если на уровне `program` находятся прочие инструкции - ошибка выполнения

**Пример:**

```Udav
let c = 3 # ошибка: на этом уровне можно только объявлять переменные

fun foo(): # может быть объявлена
    pass 

fun main():
    let a = 3 
    fun bar(): # ошибка: язык не поддерживает вложенные функции
        print(a) 
```

#### Инструкции на уровне [block](grammar.ebnf)

Допустимые инструкции на уровне `block`

- Объявление переменной.
- Оператор присваивания.
- Вызов функции
- `if`.
- `while`.
- `break`|`continue`
- `pass`

Если на уровне `block` находятся прочие инструкции - ошибка выполнения

**Пример:**

```Udav
fun main():
    let a = 3 
    a = 5
    println(a)
    if a > 0:
        println("Positive")
    while a < 10:
        a = a + 1
    let b = readln()
```

### Объявление переменной

#### Объявление с инициализацией

В Udav каждая переменная должна быть объявлена с начальным значением\
*Если переменная не проинициализирован при объявлении, то выполнение завершается ошибкой выполнения*

```Udav
let i = 1
let i = "string"
let a # ошибка выполнения
```

#### Множественное объявление

В Udav поддерживается множественное объявление переменных с типами,
определёнными на основе значений. В одной строке можно объявить несколько переменных.

```Udav
let a = 1, b = "string", c = 3
```

#### Повторное объявление

Повторное объявление переменной запрещено. Результат - ошибка выполнения

```udav
let a = 3
let a = 2 # ошибка выполнения
```

#### Область действия переменных

Локальная область действия переменной — это ограниченная часть программы, внутри которой
имя переменной связано с конкретным объявлением и может быть использовано для обращения к
соответствующему значению.

Имя переменной доступно только внутри [block](grammar.ebnf), где она была объявлена.
Попытка обратиться к имени, которого не существует в блоке - ошибка выполнения

```Udav
fun foo():
    print(a)  # Ошибка: обращение к `a` хоть и находится на одном уровне с её объявлением, недоступна, так как находится в другой функции

fun main():
    let a = 3
    if true:
        print(a)  # символ `a` доступен
        let b = "2"
    print(b)  # Ошибка: Область действия `b` не распространяется на эту строку
    foo()
```

### Присвоение переменной

Оператор присваивания используется для изменения значения переменной

#### Операторы присваивания

| Оператор | Описание                      |
|----------|-------------------------------|
| `=`      | Присваивание                  |
| `+=`     | Присваивание с сложением      |
| `-=`     | Присваивание с вычитанием     |
| `*=`     | Присваивание с умножением     |
| `/=`     | Присваивание с делением       |
| `%=`     | Присваивание с остатком       |
| `**=`    | Присваивание со степенью      |
| `\|=`    | Побитовое ИЛИ с присваиванием |
| `&=`     | Побитовое И с присваиванием   |
| `^=`     | Побитовый XOR с присваиванием |
| `>>=`    | Сдвиг вправо с присваиванием  |
| `<<=`    | Сдвиг влево с присваиванием   |

#### Динамическая типизация

Тип переменной автоматически меняется при изменении значения. \

**Пример:** если переменная `a` была целого типа, но в последующей логике
ей присвоили значение строкового типа, то значение и тип переменной поменяются без ошибок

```udav
let a = 1
a = "1" # ошибки нет
```

#### Составной оператор присваивания

Составной оператор присваивания — это бинарный оператор, который объединяет:

- вычисление бинарной операции над текущим значением левого операнда и правым операндом
- присваивание результата обратно левому операнду

На все составные операторы распространяются [правила типов](expressions.md#типы-выражений), с которыми они применяются

Пример: использование оператора `<<=` со строковым или целым отрицательным типом данных - ошибка выполнения

#### Составное присвоение

Составного присвоения (подобно объявлению) - нет. Попытка поменять значения в 1 строке - ошибка выполнения

```udav
a = 3, b = "11" # ошибка
```

### Вызов функции

Любая функция может быть вызвана в виде инструкции [stmt](grammar.ebnf)

В таком случае значение, которое она вернула, отбрасывается.

```udav
fun get_pentagon_password():
    return "12345Q"
    
fun main():
    get_pentagon_password() # значение утрачено :(
```

#### Функции вывода в консоль

Для вывода в консоль используются встроенные функции:

```Udav
print(...)
println(...)
```

`...` означает, что на вход подаётся произвольное количество параметров.
Обе функции выводят значения, разделяя их пробелом.

Функции `print` и `println` возвращают `null`.

**Примеры:**

```Udav
println()  # Печать пустой строки
println(a, 1, "string", foo())  # Печать нескольких значений
println(println()) # null
```

### Управление потоком

#### Ветвления

##### Условный оператор if

Пример:

```udav
if x > 0:
    result = "positive"
```

##### Конструкция if-else

Пример:

```udav
if x > 0:
    result = "positive"
else:
    result = "non-positive"
```

##### Конструкция if-elif-else

Пример:

```udav
if x > 0:
    result = "positive"
elif x < 0:
    result = "negative"
else:
    result = "zero"
```

##### Семантика if-else

Ветвью в конструкции if-else называется условие и блок кода, следующий за этим условием, после ключевых слов if/elif. Также существует особая ветвь else, не имеющая условия. Ветви конструкции if-else упорядоченны по порядку объявления в коде. Например, в примере ниже, у конструкции if-else есть три ветви.

```udav
if x > 0:
    result = "positive"
elif x < 0:
    result = "negative"
else:
    result = "zero"
```

При выполнении конструкции if-else берётся первая ветвь, вычисляется её условие. Если тип вычисленного условия не boolean, то возникает ошибка выполнения. Если значение false, то данный алгоритм начинается снова, при этом текущая ветвь отбрасывается. Если значение true, то блок кода, связанный с данной ветвью, выполняется, а выполнение текущей конструкции if-else завершается. Если алгоритм доходит до ветви else, то она выполняется.

#### Цикл `while`

Цикл while — это управляющая конструкция, предназначенная для многократного выполнения 
тела цикла, пока логическое условие остаётся истинным

```udav
let i = 0
while i < 5:
    print(i)
    i += 1
```

Условие цикла вычисляется перед каждой итерацией. Если тип условия не boolean, то возникает ошибка выполнения. Если условие истинно, выполняется тело цикла. Если услови ложно, выполнение конструкции while завершается. 

##### break

`break` — это инструкция управления потоком выполнения, предназначенная для 
немедленного завершения ближайшего охватывающего цикла

Пример:

```udav
let i = 0
while True:
    if i >= 5:
        break
    print(i)
    i += 1
```

##### continue

`continue` — это инструкция управления потоком выполнения, предназначенная 
для немедленного завершения текущей итерации ближайшего охватывающего цикла и 
перехода к следующей итерации

Пример:

```udav
let i = 0
while i < 5:
    i += 1
    if i % 2 == 0:
        continue
    print(i)
```

### pass

`pass` — это пустая инструкция, не выполняющая никаких действий.

### return

`return` — это инструкция управления потоком выполнения, предназначенная для немедленного 
завершения выполнения текущей функции с возможной передачей возвращаемого 
значения вызывающему контексту

```udav
fun a():
    let a = 3
    return a
    format_hard_drive() # функция не вызовется
```

Вызов `return` не обязателен для функции, если его не будет, функция завершится, вернув null

```udav
fun a():
    let a = 3 # не ошибка
```

Вызов `return` без параметра эквивалентно вызову `return null`

```udav
fun a():
    return # То же самое, что и "return null"
```
