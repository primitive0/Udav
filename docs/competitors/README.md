# Сравнение C++ и Python для фронтенда учебного компилятора

## 1. Синтаксис циклов, ветвлений и блоков кода

| Особенность         | C++                                                           | Python                                                  |
| ------------------- | ------------------------------------------------------------- | ------------------------------------------------------- |
| Блоки кода          | Фигурные скобки `{}`                                          | Отступы (4 пробела/таб)                                 |
| Ветвление           | `if (cond) { ... } else if (...) { ... } else { ... }`        | `if cond: ... elif ...: ... else: ...`                  |
| Циклы               | `for (int i = 0; i < n; i++)`, `while (cond)`                 | `for i in range(n):`, `while cond:`                     |
| Инструкция выхода   | `break`, `continue`, но нужно учитывать особенности их работы | те же `break`, `continue`                               |
| Инструкция `switch` | Есть (`switch-case`)                                          | Нет, заменяется на `if-elif` или `match` (Python 3.10+) |

**Вывод:**  
В Python блоки определяются отступами — это упрощает парсинг, но требует учёта уровня вложенности.
В C++ структура определяется скобками, что проще для лексического анализа.

---

## 2. Объявление типов переменных и параметров

| Особенность       | C++                                    | Python                                                                     |
| ----------------- | -------------------------------------- | -------------------------------------------------------------------------- |
| Объявление        | `int x = 5;`                           | `x = 5`                                                                    |
| Типизация         | Статическая                            | Динамическая                                                               |
| Параметры функций | `int f(int x, float y)`                | `def f(x, y):` (тип можно аннотировать: `def f(x: int, y: float) -> int:`) |
| Вывод типа        | Частично автоматический (C++11 `auto`) | Полностью динамический                                                     |

**Вывод:**  
Фронтенд для Python не требует анализа типов на этапе синтаксиса, в отличие от C++, где типизация — часть грамматики и семантики.

---

## 3. Набор типов данных

| Категория            | C++                                        | Python                          |
| -------------------- | ------------------------------------------ | ------------------------------- |
| Целые                | `int`, `long`, `short`, `unsigned`         | `int` (неограниченной точности) |
| Вещественные         | `float`, `double`, `long double`           | `float` (64-бит)                |
| Символы              | `char`                                     | `str` длиной 1                  |
| Строки               | `std::string`                              | `str`                           |
| Логические           | `bool`                                     | `bool`                          |
| Коллекции            | массивы, `std::vector`, `std::map`, и т.д. | `list`, `dict`, `set`, `tuple`  |
| Специальное значение | `nullptr`                                  | `None`                          |

**Вывод:**  
Python имеет более простую и унифицированную систему типов. В C++ типы и квалификаторы (`const`, `unsigned`) усложняют грамматику.

---

## 4. Набор операторов

| Категория          | C++                            | Python                 |
| ------------------ | ------------------------------ | ---------------------- |
| Арифметические     | `+ - * / % ++ -- + - * / % **` |
| Логические         | `&&`, `!`, `and`, `or`, `not`  |             
| Сравнения          | `== != < > <= >=`              | те же                  |
| Присваивания       | `= += -= *= /= %= ++ --`       | `= += -= *= /= %= **=` |
| Побитовые          | `& ^ ~ << >>`                  | те же                  |
| Индексация         | `arr[i]`                       | `arr[i]`               |
| Операторы доступа  | `.` и `->`                     | `.`                    |
| Тернарный оператор | `cond ? a : b`                 | `a if cond else b`     |

**Вывод:**  
Семантика операторов близка, но синтаксис и приоритеты различаются. Для Python проще грамматика.

---

## 5. Пользовательские функции

| Особенность                 | C++                              | Python                                     |
| --------------------------- | -------------------------------- | ------------------------------------------ |
| Объявление                  | `int f(int x) { return x + 1; }` | `def f(x): return x + 1`                   |
| Перегрузка                  | Да                               | Нет                                        |
| Шаблоны                     | Есть (`template <typename T>`)   | Аналог — generics (Python 3.9+, аннотации) |
| Возврат нескольких значений | Через `std::tuple` или `struct`  | Через кортеж `return a, b`                 |

**Вывод:**  
Python-функции проще для синтаксического анализа. В C++ — сложнее из-за перегрузок и шаблонов.

---

## 6. Пользовательские структуры

| Особенность  | C++                               | Python                                                          |
| ------------ | --------------------------------- | --------------------------------------------------------------- |
| Объявление   | `struct Point { int x; int y; };` | `class Point: def __init__(self, x, y): self.x = x; self.y = y` |
| Инкапсуляция | `public`, `private`, `protected`  | Всё публичное по умолчанию                                      |
| Конструкторы | Явно определяются                 | Через `__init__`                                                |
| Методы       | В теле структуры/класса           | Внутри класса с `self`                                          |

**Вывод:**  
C++ имеет строгую структуру классов и модификаторы доступа. Python — гибче, но с более динамической моделью.

---

## 7. Управление памятью

| Особенность   | C++              | Python                                        |
| ------------- | ---------------- | --------------------------------------------- |
| Выделение     | `new`, `malloc`  | Автоматически                                 |
| Освобождение  | `delete`, `free` | Сборщик мусора                                |
| RAII          | Да               | Частично (через контекстные менеджеры `with`) |
| Утечки памяти | Возможны         | Редки, но возможны при циклических ссылках    |

**Вывод:**  
Для Python фронтенд не требует анализа управления памятью. В C++ нужно учитывать область видимости и освобождение.

---

## 8. Обработка ошибок

| Особенность                 | C++                                 | Python                         |
| --------------------------- | ----------------------------------- | ------------------------------ |
| Исключения                  | `try { ... } catch (...) { ... }`   | `try: ... except ...:`         |
| Проброс                     | `throw e;`                          | `raise e`                      |
| Пользовательские исключения | Через наследование `std::exception` | Через наследование `Exception` |
| Альтернатива                | Возврат кодов ошибок                | Исключения — основной способ   |

**Вывод:**  
Механизм похож, но Python не требует объявления типов исключений, упрощая грамматику.
