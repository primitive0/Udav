# Синтаксис выражений: сравнение C++ и Python (фокус на числах)

## 1. Числовые типы данных

### Сравнение

| Аспект                     | C++                                                         | Python                                        |
|----------------------------|-------------------------------------------------------------|-----------------------------------------------|
| Базовые целые              | `short`, `int`, `long`, `long long` (+ `signed`/`unsigned`) | `int` (произвольной длины)                    |
| Фиксированная разрядность  | Есть (`std::int32_t`, `std::uint64_t` и т.д.)               | Нет                                           |
| Вещественные               | `float`, `double`, `long double`                            | `float` (обычно IEEE754 double)               |
| Целочисленное переполнение | Неопределённое/зависящее от реализации для знаковых типов   | Нет переполнения (`int` — big-int)            |
| Деление целых              | `/` → целочисленное деление для целых типов                 | `/` всегда даёт `float`, `//` — целочисленное |
| Модуль                     | `std::abs` / `std::fabs`                                    | `abs()`                                       |
| Комплексные                | Через `std::complex<T>`                                     | Встроенный тип `complex`                      |

C++ имеет богатую, но статически фиксированную систему числовых типов и явные модификаторы, влияющие на семантику
выражений.
Python имеет небольшой набор встроенных числовых типов и полагается на динамику и автоматическое расширение диапазона
целых.

## 2. Арифметические операторы

### Сравнение операторов

| Категория                    | C++                                               | Python                                            |
|------------------------------|---------------------------------------------------|---------------------------------------------------|
| Унарные                      | `+a`, `-a`, `++a`, `a++`, `--a`, `a--`            | `+a`, `-a`                                        |
| Базовые бинарные             | `a + b`, `a - b`, `a * b`, `a / b`, `a % b`       | то же                                             |
| Целочисленное деление        | Нет отдельного оператора; для целых деление — `/` | `a // b`                                          |
| Степень                      | Нет оператора (используют `std::pow(a, b)`)       | `a ** b`                                          |
| Сдвиги (по битам)            | `a << b`, `a >> b`                                | есть те же операторы                              |
| Комбинированные присваивания | `+=`, `-=`, `*=`, `/=`, `%=`, `<<=`, `>>=`, …     | есть те же (`+=`, `-=`, `*=`, `/=`, `//=` и т.д.) |

Ключевые различия:

* В C++ `/` для целых типов — целочисленное деление, результат имеет целый тип (с отсечением дробной части).
* В Python `/` всегда возвращает `float`, а целочисленное деление делается через `//`.
* Python имеет оператор `**` со своей приоритетностью и правоассоциативностью; в C++ степенная операция — только
  функция.

## 3. Приоритеты операций

### Сравнение приоритетов (ограничимся наиболее важными для чисел)

Сверху вниз — от высшего приоритета к низшему.

#### C++ (подмножество)

| Уровень | Примеры операторов               | Комментарий               |
|---------|----------------------------------|---------------------------|
| 1       | постфикс `a++`, `a--`            | к числам тоже применимо   |
| 2       | префикс `++a`, `--a`, `+a`, `-a` | унарные                   |
| 3       | `*`, `/`, `%`                    | умножение/деление/остаток |
| 4       | `+`, `-`                         | сложение/вычитание        |
| 5       | `<<`, `>>`                       | сдвиги                    |
| 6       | `<`, `<=`, `>`, `>=`             | сравнение                 |
| 7       | `==`, `!=`                       | равенство                 |
| 8       | `&`, `^`, `\|`                   | побитовые                 |
| 9       | `&&`                             | логическое И              |
| 10      | `\|\|`                           | логическое ИЛИ            |
| 11      | `?:`                             | условный оператор         |
| 12      | `=`, `+=`, …                     | присваивание              |

#### Python (подмножество)

| Уровень | Примеры операторов               | Комментарий                  |
|---------|----------------------------------|------------------------------|
| 1       | `x ** y`                         | степень, правоассоциативна   |
| 2       | унарные `+x`, `-x`, `~x`         |                              |
| 3       | `*`, `/`, `//`, `%`              |                              |
| 4       | `+`, `-`                         |                              |
| 5       | сдвиги `<<`, `>>`                |                              |
| 6       | `&`                              | побитовое И                  |
| 7       | `^`                              | побитовое XOR                |
| 8       | `\| `                            | побитовое ИЛИ                |
| 9       | сравнения `<`, `>`, `==`, и т.п. | можно «цепочкой» `a < b < c` |
| 10      | `not`                            | логическое отрицание         |
| 11      | `and`                            | логическое И                 |
| 12      | `or`                             | логическое ИЛИ               |

Ключевые различия:

* `**` в Python имеет высокий приоритет и правоассоциативность: `2 ** 3 ** 2` = `2 ** (3 ** 2)`.
* В C++ нет `**`, и приоритетная структура строится вокруг `* / %`, `+ -`, сдвигов, битовых и логических операторов.
* В Python логические `not`, `and`, `or` реализованы как ключевые слова, а не как `!`, `&&`, `||`.

## 4. Лево- и правоассоциативные операторы

### C++

Для числовых и логических операторов (упрощённо):

**Левоассоциативные:**

* `*`, `/`, `%`
* `+`, `-`
