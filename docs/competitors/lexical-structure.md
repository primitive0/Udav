# Lexical Structure: C++ vs Python

## Overview

Сравнение лексической структуры императивной части языков C++ и Python.

## 1. Базовые элементы лексики

### Таблица сравнения

| Элемент                     | C++                                | Python                        |
|-----------------------------|------------------------------------|-------------------------------|
| Комментарии                 | `//`, `/* */`                      | `#`                           |
| Разделители                 | `;`, `{}`, `()`                    | `:`, отступы, `()`            |
| Чувствительность к отступам | Нет                                | Да                            |
| Чувствительность к регистру | Да                                 | Да                            |
| Строковые литералы          | `"text"`, `'text'`, raw-строки     | `"text"`, `'text'`, `r"text"` |
| Числовые литералы           | int, float, suffix (`u`, `l`, `f`) | int, float, без суффиксов     |

### Примеры

**C++**:

```cpp
int x = 10;
int y = 3; int z = 4;
// comment
```

**Python**:

```python
x = 10
# comment
```

---

## 2. Блоки кода

| Особенность            | C++       | Python         |
|------------------------|-----------|----------------|
| Определение блока      | `{ ... }` | Отступы        |
| Разделитель инструкций | `;`       | Перевод строки |

**Примеры**:

C++:

```cpp
{
    int x = 1;
}
```

Python:

```python
if True:
    x = 1
```

---

## 3. Ветвления

| Особенность     | C++                     | Python               |
|-----------------|-------------------------|----------------------|
| Ключевые слова  | `if`, `else if`, `else` | `if`, `elif`, `else` |
| Синтаксис блока | `{}`                    | `:` + отступ         |

**Примеры**:

C++:

```cpp
if (x > 0) {
} else if (x == 0) {
} else {
}
```

Python:

```python
if x > 0:
    pass
elif x == 0:
    pass
else:
    pass
```

---

## 4. Циклы

| Особенность      | C++                  | Python                |
|------------------|----------------------|-----------------------|
| Цикл while       | есть                 | есть                  |
| Цикл for         | счетчик или итератор | итерация по коллекции |
| Доп. конструкции | `do { } while`       | нет                   |

**Примеры**:

C++:

```cpp
for (int i = 0; i < 10; i++) {}
```

Python:

```python
for i in range(10):
    pass
```

---

## 5. Функции

| Особенность | C++                         | Python                      |
|-------------|-----------------------------|-----------------------------|
| Объявление  | возвращаемый тип обязателен | тип возврата не указывается |
| Параметры   | типы обязательны            | типы не требуются           |
| Возврат     | `return`                    | `return`                    |

**Примеры**:

C++:

```cpp
int add(int a, int b) {
    return a + b;
}
```

Python:

```python
def add(a, b):
    return a + b
```

---

## 6. Ввод/вывод и встроенные функции

| Особенность        | C++                                | Python         |
|--------------------|------------------------------------|----------------|
| Ввод               | `std::cin`                         | `input()`      |
| Вывод              | `std::cout`                        | `print()`      |
| Встроенные функции | ограничены стандартной библиотекой | обширный набор |

**Примеры**:

C++:

```cpp
std::cout << "Hello";
```

Python:

```python
print("Hello")
```

---

## 7. Типы данных

| Тип          | C++                    | Python               |
|--------------|------------------------|----------------------|
| Целые        | `int`, `long`, `short` | `int`                |
| Вещественные | `float`, `double`      | `float`              |
| Строки       | `std::string`          | `str`                |
| Массивы      | `std::vector`, `T[]`   | `list`               |
| Структуры    | `struct, class`        | `class` с атрибутами |

**Пример структуры**:

C++:

```cpp
struct Point {
    int x;
    int y;
};
```

Python:

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y
```

## 8. Операторы

### Арифметические

| Оператор              | C++        | Python     |
|-----------------------|------------|------------|
| `+ - * /`             | да         | да         |
| Целочисленное деление | `/` и `%`  | `//` и `%` |
| Степень               | `std::pow` | `**`       |

### Логические

| Оператор | C++    | Python |
|----------|--------|--------|
| И        | `&&`   | `and`  |
| ИЛИ      | `\|\|` | `or`   |
| НЕ       | `!`    | `not`  |

### Сравнение

| Оператор          | C++ | Python |
|-------------------|-----|--------|
| `== != < > <= >=` | да  | да     |

**Примеры**:

C++:

```cpp
if (a && b) {}
```

Python:

```python
if a and b:
    pass
```

---

## 9. Массивы и структуры

### Массивы

| Особенность         | C++                | Python |
|---------------------|--------------------|--------|
| Статические массивы | `int a[10]`        | нет    |
| Динамические        | `std::vector<int>` | `list` |

### Структуры / записи

| Особенность   | C++                            | Python      |
|---------------|--------------------------------|-------------|
| Синтаксис     | `struct`                       | `class`     |
| Инициализация | агрегатная и через конструктор | конструктор |
